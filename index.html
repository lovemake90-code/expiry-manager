상품 자료 엑셀·CSV 가져오기
헤더 예시: 바코드, 상품명, 판매코드, 상품코드, 규격, 저울ID (또는 barcode, name, salesCode, scaleId). XLSX는 인터넷 연결 시 라이브러리를 불러옵니다. CSV는 오프라인으로 가져올 수 있습니다.
📥 사진 판독 결과 가져오기 (V40 · 대표 이미지 자동 보완)
검수용 JSON을 불러오면 상품 앞면·뒷면 중 대표 이미지를 선택하거나 사진을 새로 찍을 수 있습니다. 사진을 누르면 확대되고, 상품명·바코드·소비기한은 수정 가능합니다. 기존 바코드가 있으면 기존 상품명을 연결합니다. 대표 이미지가 있으면 그대로 유지하고, 이미지가 없을 때만 앞면·뒷면 선택 또는 촬영·갤러리 사진을 대표 이미지로 저장할 수 있습니다. 없는 바코드는 신규 상품으로 구분합니다. 선택 항목만 등록하며 기존 자료는 덮어쓰지 않습니다.
검수 파일을 선택해 주세요.

📥 기존 엑셀 145건 사진포함 추가 등록 (V36)


이전 엑셀에서 만든 등록자료 JSON 전용입니다. 바코드가 없는 상품도 원본 고유번호로 구분합니다. 기존 상품·소비기한 기록은 삭제하거나 덮어쓰지 않고, 중복은 제외합니다. 자료는 현재 기기 브라우저에만 보관됩니다.


먼저 '전체 백업 (JSON)'을 눌러 현재 데이터를 보관한 다음 파일을 선택하세요.






전체 데이터 백업 · 복원
기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터 삭제·기기 변경 시 사라질 수 있으므로 JSON 백업을 권장합니다. 백업에는 상품 및 소비기한 정보가 들어가므로 안전하게 보관하세요.
폴드8 설치·사용 안내
① 이 HTML 파일은 상품 검색, 수동 입력, 재고 관리, CSV 내보내기를 오프라인에서도 사용할 수 있습니다.
② 실시간 카메라 스캔은 HTTPS 웹 주소에서 열어야 안정적으로 작동합니다. Chrome/삼성 인터넷 브라우저에서 카메라 권한을 허용하세요.
③ HTTPS에서도 브라우저별 카메라·바코드 지원 차이가 있어 일부 기기에서는 인터넷 연결이 필요합니다.
④ 온라인 배포 후 브라우저의 ‘홈 화면에 추가’를 이용하면 앱처럼 실행할 수 있습니다.
⑤ 엑셀에서 열리는 CSV를 기본으로 저장하며, 한글이 깨지지 않도록 UTF-8 BOM을 포함합니다.
